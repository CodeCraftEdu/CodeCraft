# Références de recette historiques

Ces scénarios datés décrivent une ancienne navigation et des composants remplacés. Ils sont conservés pour retrouver leurs cas détaillés ; ils ne sont pas des commandes de validation actuelles. Ils ne sont pas inclus dans `npm test` ni dans `npm run test:browser`.

La suite active, les correspondances et ses limites sont décrites dans [la recette de développement](../../docs/verification-developpement.md). Réintroduire un cas utile dans une suite active après avoir vérifié ses attentes avec le contenu actuel.
